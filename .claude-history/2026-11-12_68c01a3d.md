## Claude（2026-11-12 19:18）

あります。対戦でプレイヤーが取る行動（どの動きを選ぶか）は、3段に分けて定義しています。

## 1. ターンのない土台：`Step`（`CardGen/Model.lean:399`）
1手で盤面がどう変わってよいかを、関係（`State → State → Prop`）として書いたものです。手の種類は次のとおりです。

| 手 | 中身 |
|---|---|
| `draw` | デッキの一番上を引く |
| `place` | 手札のカードをゾーンのマスに置く |
| `resolve` | フィールドのカードの効果を発動して解決する |
| `attack` | フィールドのカードで攻撃する |
| `combat` | MTG 式の戦闘（攻撃とブロックをまとめて行う） |
| `mend` | どのカードのダメージも 0 に戻す |
| `trigger` | 誘発した効果を解決する |
| `discard` | 手札を1枚捨てる |
| `settle` | 状態の確認（ダメージで破壊されるカードを片付ける） |

`Reachable`（`Model.lean:440`）は「開始時からこれらの手を繰り返して届く盤面」です。★の多くは、この上で証明しています。

## 2. 実際に動かす版：`Choice` と `State.step?`（`CardGen/Play.lean:15`）
プレイヤーが選ぶ動きを、データとして並べたものです。`State.step?` は選んだ動きを実行し、できない動きなら `none` を返します。中身は `Step` と同じ9種類です。`step?_sound`（`step?` で動いた結果は `Step` でも許される）を証明していて、凍結した主張にも入っています。

## 3. ターンのある対戦：`TChoice` と `Match.step?`（`CardGen/Turn.lean:131`）
誰が、いつ、何をしてよいかを足した版です。手の種類は次のとおりです。

- 置く：`place`（ターンプレイヤー）・`cast`（相手がインスタントを置く）
- 効果：`resolve`・`trigger`
- 戦闘：`attack`・`block`
- マナ：`tap`・`oppTap`
- 進行：`endTurn`・`pass`（優先権を渡す）
- そのほか：`settle`・`discard`

`TReachable`（`Turn.lean:535`）が、この版での「届く盤面」です。`Match.Moved`（`Turn.lean:543`）は、ターンのある1手が `Step` の0回以上の繰り返しに収まることを示す橋渡しです。

## 参考：カードの効果の中身
効果が解決したときに起きることは、プレイヤーの行動とは別に `Action`（`CardGen/IR.lean:182`）で定義しています。`destroy`・`bounce`・`draw`・`damage`・`heal`・`strike`・`pump`・`counter` です。

「ユーザー」が対戦のプレイヤーではなく、Unity のエディタで操作する人のことでしたら、そちらの操作は C# と Unity 側にあります（`csharp/`・`unity/`）。必要ならそちらを調べます。
