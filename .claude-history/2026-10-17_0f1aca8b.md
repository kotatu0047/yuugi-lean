## ルールを2層に分ける

| 層 | 内容 | 入力例の該当箇所 |
|---|---|---|
| 盤面の制約 | どんな盤面があり得るか | 7・8（ゾーンに置けるカードの種類）、1マス1枚、★9〜12、総数80枚 |
| 手順の規則 | ゲームが何をどの順で行うか | 初期手札5枚、ドローは1枚、通常召喚は1ターンに1回、手札の上限 |

「破壊されていないモンスターは破壊されない」は、どちらの層のルールでもありません。何もしなければ盤面は変わらない、という前提にすぎません。

カードの効果とは、手順の規則にない動きを新しく足すものです。サンダーボルトは「相手のモンスターをすべて、持ち主の墓地へ送る」という動きを足します。どのゾーンにもふさわしい種類のカードしかなく、枚数も保たれるので、盤面の制約は1つも破っていません。

| カード | 何を変えるか | プロトタイプで |

| サンダーボルト、ハーピィの羽根帚 | 動きを足すだけ（モンスターゾーンや魔法罠ゾーンから墓地へ） | **使える** |

## 1. スクリプトを作る

`.claude/hooks/save-history.sh`

```bash
#!/usr/bin/env bash
set -euo pipefail

input=$(cat)
transcript=$(echo "$input" | jq -r '.transcript_path')
session=$(echo "$input" | jq -r '.session_id')

dest="${CLAUDE_PROJECT_DIR}/.claude-history"
mkdir -p "$dest"

# 生ログ（JSONL）をそのまま保存
cp "$transcript" "$dest/${session}.jsonl"

# 読みやすい Markdown 版も作る（テキスト部分のみ）
jq -r '
  select(.type=="user" or .type=="assistant")
  | .message.content as $c
  | (if ($c|type)=="string" then $c
     else ([$c[]? | select(.type=="text") | .text] | join("\n")) end) as $t
  | select($t != "")
  | "## \(.type)\n\n\($t)\n"
' "$transcript" > "$dest/${session}.md"
```

```bash
chmod +x .claude/hooks/save-history.sh
```

（`jq` が必要です。macOS なら `brew install jq`）

## 2. フックを登録する

`.claude/settings.json`（チームで共有する場合）または `.claude/settings.local.json`（自分だけの場合）に追加します。

```json
      {
        "hooks": [
          { "type": "command", "command": "\"$CLAUDE_PROJECT_DIR\"/.claude/hooks/save-history.sh" }

      }

      {
        "hooks": [

        ]
      }
    ]
  }
}
```
