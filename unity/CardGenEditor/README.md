# CardGen Editor（Unity・実行時のアプリ）

ノードをつないでカードゲームのルールとカードを作り、その場で形式を検査し、Lean の検査ツールで★と無効の関係を検査するエディタ。

## 開き方

Unity は WSL のファイルシステム上のプロジェクトを開けない（大文字小文字を区別するため）。
Windows 側のクローン（例：`C:\Users\yamam\repo\yuugi-lean`）の `unity/CardGenEditor` を Unity Hub で開く（Unity 6000.6.6f1）。

- メニュー「CardGen ＞ プロジェクトを準備」：PanelSettings とシーン（`Assets/CardGenEditor/Main.unity`）がなければ作る
  （シーンを作り直したいときは、ファイルを消してから実行する）
- メニュー「CardGen ＞ Windows 用にビルド」：`Build/CardGenEditor.exe` を作る

C# の中核（中間表現・形式の検査・盤面の計算）は `csharp/CardGen.Core` をローカルのパッケージとして使う。

### WSL で編集して、Windows 側でビルドする

Windows 側のクローンは「ビルド用の写し」として扱い、編集は WSL 側で行う。WSL から次のスクリプトで写してビルドする。

```
tools/unity-build.sh                         # 作業中のファイルを Windows 側に写し、バッチモードでビルドする
tools/unity-build.sh --reset                 # 先に Windows 側のクローンの変更を捨てて git pull する
tools/unity-build.sh --shot 画面.png -cardgen-play 7   # ビルドしたアプリを動かし、画面を保存する
```

Windows 側のクローンの場所は `CARDGEN_WIN_REPO`、Unity.exe は `CARDGEN_UNITY` で変えられる
（既定は Windows のユーザーフォルダの `repo/yuugi-lean` と、`ProjectVersion.txt` の版の Unity Hub のエディタ）。

## 使い方

| 操作 | やり方 |
|---|---|
| 移動・拡大縮小 | 背景をドラッグ・ホイール |
| ノードを動かす・選ぶ | ノードをドラッグ・クリック |
| つなぐ | 右の丸から別のノードの左の丸へドラッグ（ルール→ゾーン、カード→発動・無効、発動→破壊・手札に戻す・ドロー、破壊・手札に戻す・無効→範囲） |
| つなぎを外す | 左の丸をクリック |
| 追加 | 上の「追加」。ノードを選んだまま追加すると、そのノードからつないだ状態で追加する |
| 開く・保存 | パスを入れて「開く」「保存」（中間表現の JSON。古い版のファイルは開くときに今の版 6 に上げる） |
| 検査 | 形式の検査は編集のたびに自動。★と無効の関係は「Lean で検査」 |
| マスの位置 | ゾーンのノードの「マスの位置」に「列,行」をマスの数だけ並べる（例：`22,25 23,25 24,25 25,25 26,25`）。「マスの数だけ横に並べる」で左端の列と行から作れる。盤面全体は 49×49 で、相手の側は点対称の位置になる |
| 隣・同じ縦列 | 範囲のノードの「マスの関係」で選ぶ（破壊・手札に戻す・攻撃力の変化で使える） |
| マナ・タップ | カードのノードの「コスト」（どの色でも払える分と、色の決まった分）、「タップで出るマナ」の量と色。ルールのノードの「マナの色」。ルールのノードの「種類ごとの上限」（例：`土地=1`）、「攻撃するとタップする」「召喚酔い」「MTG 式の戦闘」 |
| MTG 風の見本 | 上の「見本（MTG 風）」で読み込む（土地・クリーチャー・ソーサリー・エンチャント） |

## テストプレイ

上の「テストプレイ」で、作ったルールとカードを両プレイヤー分1人で動かせる（デッキはカードの一覧を繰り返して混ぜたもの）。

- ドロー・手札を置く・魔法を発動する・攻撃する。動きは C# の対戦エンジン（Lean の `State.step?` と差分テスト済み）で進める
- ライフ（ルールの初期ライフが 0 でなければ）と勝敗、戦闘できるカードの攻撃力・守備力（無効にされていない攻撃力の変化を足したもの）を表示する
- **ターン：** C# の `Match`（Lean の `CardGen/Turn.lean` と差分テスト済み）で進める。「ターン終了」で相手のターンになり、
  新しいターンプレイヤーがルールの枚数を引く。カードを置く・攻撃するのはターンプレイヤーだけで、場のカードの発動はどちらの
  ターンでもできる。戦闘できるカードを置けるのは1ターンにルールの回数まで、攻撃は1ターンに1枚1回まで、先攻の最初のターンは
  ルールで許したときだけ攻撃できる。「相手の先攻で最初から」で先攻を入れ替えられる。ターンのルールはルールのノードで決める
- **マナとタップ：** マナを出すカードを選んで「タップしてマナを出す」。手札のカードはコストの分のマナがあれば置ける。
  マナは色ごとの数で表示し（例：赤2・緑1）、色の決まったコストはその色で、残りは無色のマナから先に自動で払う。
  タップしているカードは薄く表示し、マナはターンの終わりに消える。召喚酔いのカードには「召喚酔い」と出る
- **ブロック（MTG 式の戦闘）：** 攻撃を宣言すると、右側に「ブロック」の欄が出て、攻撃されたプレイヤーが
  ブロックするカード（結果も表示）か「ブロックしない」を選ぶ
- **無効の状態：** フィールドのカードごとに、効果が「有効・無効」かを表示する。カードが適用された順番を覚えておき、
  盤面が変わるたびに OCG の手順（Lean の `CardGen/Timed.lean` の `TSys.succ`。C# では `Judge`）で判定を進める。
  互いに無効にし合う2枚は先に適用された方が勝ち（相手の Bloo－D がいるところに出した自分の Bloo－D は無効）、
  同時に適用を始めるカードはターンプレイヤーのものが先になる。どう選んでも結果が1通りならそこまで自動で進め、
  プレイヤーが選ぶ場面（同じプレイヤーのカードを複数、有効に戻せるときなど）だけ選択肢を出す。判定が止まらない盤面ではそう表示する
- **マス目：** マスの位置があるゾーンは、盤面のマス目の並び（上が相手、下が自分）で表示する。手札を選ぶと、置ける空きのマスに
  「ここに置く」が出る（右の欄で表側・裏側を切り替える）。「隣」「同じ縦列」の効果はこの並びで決まる
- 盤面の制約（枚数・置けるゾーン・1マス1枚）が成り立っているかを毎回表示する（Lean で証明済みなので、崩れたら C# 側の誤り）

## Lean による検査

「Lean で検査」は、右の欄のコマンドで検査ツールを動かす。既定は WSL の中のビルド済みの検査ツール：

```
wsl.exe --cd ~ -e repo/yuugi-lean/.lake/build/bin/cardgen -
```

（WSL のホームの `repo/yuugi-lean` にあるリポジトリの検査ツール。WSL 側で `lake build` しておく。
別の場所に置いたときは欄を書き換えるか、環境変数 `CARDGEN_COMMAND` にコマンドを入れる。欄の値は次回も使われる。
アプリは Lean のコンパイラを動かさず、ビルド済みの検査ツールを呼ぶだけ）

## 命題とジョブ

右下の「命題とジョブ」で「フィールド上の、条件に合うカードは最大 n 枚」という命題を追加できる。
検査ツールが実際に対戦を進めて反例を探し、なければ証明のジョブ（`jobs/pending/`）にする。
ジョブは開発中は Claude が証明する（`jobs/README.md`）。「ジョブの状態を更新」で一覧を表示する。

## 動作確認用のコマンドライン

```
CardGenEditor.exe -cardgen-select 6 -cardgen-check -cardgen-results-end -cardgen-screenshot C:\path\shot.png
```

見本を読み込み、6番のノードを選び、Lean で検査し、結果を一番下まで送って、画面を保存して終了する。
`-cardgen-mtg` を付けると、最初に MTG 風の見本を読み込む。
`-cardgen-play 14` を付けると、テストプレイを始めて、14ターンの間、ターンごとに置ける手札を1枚置いてターンを終える。
`-cardgen-claim` を付けると、命題の欄の値でジョブを作る（実際にジョブが増えるので注意）。
